# MailAndPrint_Portfolio

Самописная конфигурация 1С:Предприятие 8 — интеграция с электронной почтой (Яндекс Почта через IMAP) и автоматизация печатных форм. Проект сделан как набор внешних обработок и доработок конфигурации под БСП.

## Платформа и зависимости

- Платформа: 1С:Предприятие 8.3
- Зависимости: БСП 3.1.11.189, без привязки к типовой конфигурации
- Режим запуска: тонкий клиент + серверная обработка

## Что автоматизировано

### Интеграция с почтой (Яндекс Почта, IMAP)

- Получение писем по кнопке, фильтр по теме «Заявка сайт».
- Обработка кодов ошибок протокола и API: 10, 4, 32, 110, 224 — с логированием и понятными сообщениями пользователю.
- Хранение профиля подключения: реквизиты/измерения + пароль в зашифрованном виде (ХранилищеЗначения).
- Создание документов/записей на основании писем (парсинг темы, вложений, тела письма).

### Печатные формы

- Динамическое имя файла при сохранении: шаблон с датой, номером документа, префиксом.
- Передача параметра `Ссылка` во внешнюю печатную форму и корректное получение представления реквизита в запросе.
- Использование механизма «Дополнительные отчёты и обработки» для подключения форм без изменения основной конфигурации.
- Подстановка данных организации/руководителя/главного бухгалтера через БСП-функции.

## Как развернуть 

1. Создать пустую базу в Конфигураторе.
2. Загрузить конфигурацию из файлов: *Конфигурация → Загрузить конфигурацию из файлов…*, указать папку `src`.
3. Внешние обработки из `ExternalProcessings` добавить через механизм «Дополнительные отчёты и обработки».
4. Настроить почтовый профиль: указать сервер IMAP, порт, логин, пароль приложения.

## Особенности реализации 

- Пароли и токены не хранятся в коде: используются параметры/константы/ХранилищеЗначения.
- Логика обработки ошибок вынесена в отдельные процедуры, сообщения адаптированы под пользователя.
- Имя файла печатной формы формируется на сервере с учётом префиксов и дат, чтобы избежать конфликтов имён.
- Для получения месяца прописью и других представлений используется стандартный подход (функция/запрос) без сторонних библиотек.
